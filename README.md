# Sistema de Matrículas Digital - I.E. José Olaya

## Descripción del Caso
Proyecto desarrollado para la Institución Educativa José Olaya, ubicada en el distrito de La Esperanza (Trujillo). Su objetivo es digitalizar y optimizar el proceso de matrícula de estudiantes y apoderados, reemplazando los registros manuales en cuadernos por un sistema robusto en Python.

Permite gestionar validaciones de datos, control de duplicados (por DNI), generación de códigos correlativos (`MAT-0001`), búsquedas rápidas, ordenamiento y almacenamiento persistente en archivos de texto (`sistema_matriculas_olaya.txt`).
